01 — Trajectoire

La philosophie comme boussole, le code comme outil.

Connu sur GitHub sous le nom PaterneLatiphe, j’enseigne la philosophie à Ouagadougou et je développe des applications desktop et web. Passer de la philosophie au code m’a donné une exigence double : une logique qui tient debout, un usage qui tient dans la vraie vie.

J’aime les contextes où l’on ne peut pas supposer Internet — un poste Windows, une école, un bureau, un téléphone en révision. C’est là que mes outils gardent leur lumière. Je préfère les trajectoires sobres aux effets spectaculaires : un bon outil guide, il n’éblouit pas.
